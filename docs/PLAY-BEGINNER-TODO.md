# Google Play 별도 버전 — 초보자용 상호 체크 리스트

> **용도:** 어비스펫을 `com.nolsoopgames.abysspet`로 Play에 올릴 때 한 줄씩 체크.  
> **상호 체크:** 각 항목에 «완료 기준»이 있음. 본인이 체크한 뒤 **다른 사람(또는 며칠 뒤 본인)이 완료 기준만 보고 재확인**하면 됨.  
> **코드 적용 여부:** 이 문서는 절차 체크리스트. 레포 Capacitor 골격은 이미 있음.  
> **관련:** [PLAY-PHASE0-CHECKLIST.md](./PLAY-PHASE0-CHECKLIST.md) · [CAPACITOR-ANDROID.md](./CAPACITOR-ANDROID.md) · [ADMOB-PLAY.md](./ADMOB-PLAY.md)

### 상호 체크 방법

1. **작업자**가 `[ ]` → `[x]` 로 바꾸고, 「증빙」칸에 날짜·스크린샷 메모.
2. **검수자**는 「완료 기준」만 보고 맞게 끝났는지 확인 → 표에 검수 이니셜.
3. 상위 단계가 안 끝나면 하위는 **하지 않음** (의존 열 참고).

## 레포에 이미 되어 있음 (다시 만들 필요 없음)

- Capacitor `android/`, `build:play` / `build:play:empty-ads`
- 광고 어댑터 (Toss / AdMob / empty)
- `assets/play-store/` 기본 에셋
- privacy/terms **문구** (배포만 남음)

체크할 때는 «새로 구현»이 아니라 위 절차·운영 작업 위주.
